# T-005: Continuous integration

- **Status:** Ready
- **Milestone:** M0
- **Depends on:** T-003, T-004
- **Requirements:** NFR-8
- **Related ADRs:** ADR-0008

## Goal
Every push and PR runs the same gates as `mise run check`, plus the e2e smoke test, on GitHub Actions.

## Scope
### In
- `.github/workflows/ci.yml` triggered on `pull_request` and on `push` to `main`. It uses `jdx/mise-action` so tool versions match `mise.toml`.
  - Job `backend`: `uv sync --frozen`, ruff, ruff-format check, mypy, and pytest (unit + integration + contract, using Docker for testcontainers) with the coverage gate. Upload `coverage.xml` as an artifact.
  - Job `frontend`: `pnpm install --frozen-lockfile`, biome ci, tsc, vitest with coverage, and the API schema drift check.
  - Job `e2e` (needs backend and frontend): start compose `db` only (BRouter is skipped in CI unless tests need it; see T-015), migrate, start the backend and the Vite preview, and run Playwright. Upload the report on failure.
  - Job `pre-commit`: `pre-commit run --all-files` (includes gitleaks).
- Caching for uv, pnpm, and Playwright browsers.
- `concurrency` group to cancel superseded runs.
- Add a CI badge to the README.

### Out
- Branch protection settings. Document the required checks in the README so the owner can enable them.

## Acceptance criteria
- [ ] AC1: A PR with a lint error fails the corresponding job.
- [ ] AC2: A PR that drops coverage below the threshold fails.
- [ ] AC3: A green PR finishes all jobs, and the e2e smoke test passes.
- [ ] AC4: Tool versions in CI come from `mise.toml` (no duplicate version pins in the workflow).

## Test plan
| AC | Level | Test |
|---|---|---|
| AC1–AC3 | CI | Verified with throwaway PRs or branches (link the runs in the completion notes) |
| AC4 | review | Workflow inspection |

## Definition of Done
- [ ] All ACs are verified
- [ ] README has the badge and the list of required checks
- [ ] Completion notes are filled in and the file is moved to `docs/features/complete/`
